# Phase 0：研究目的與控制變因

## 完成狀態

Phase 00 的固定研究基線已整理於 [research-scope.md](../research-scope.md)，包含本階段要求的研究目的、變因表、最小系統邊界圖、並排 wireframe、四工具清單、任務難度及功能納入 gate。

## 目的

把系統開發範圍收斂成能直接回答研究目的的最小研究原型。

## 研究目的

本研究探討工具介面的語意增強程度，是否影響 LLM Agent 在 SAP SD 跨文件查詢任務中的工具選擇、參數生成與任務完成表現。

## 本階段工作

1. 固定 SAP SD 訂單 → 交貨 → 請款的查詢情境。
2. 固定四個研究工具，不因實作方便而增加工具。
3. 定義 A Technical、B Typed、C Semantic 三個條件。
4. 固定三個主要評估指標。
5. 固定 WebMCP 操作模式：使用者在 ChatGPT／Codex 對話區下達任務，右側網站工作台提供工具及顯示結果。
6. 記錄排除事項：寫入交易、通用 ontology、網站內嵌 Agent Controller、Agent 固定流程、OData V4 正式比較。

## 階段產出

- 研究目的段落。
- 自變因、依變因與控制變因表。
- 最小系統邊界圖。
- 網站與 Agent 並排操作的文字版 wireframe。
- 四工具清單與任務難度分類。

## 通過條件

任何新增功能都必須能直接支援 Semantic Model 驗證、A/B/C 控制或三項主要評估指標；否則暫不納入。

## 論文素材

緒論中的研究目的、研究範圍、研究貢獻與問題定義。
